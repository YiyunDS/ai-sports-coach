# Starter prompt: Health & Dryland Coach (branch `health-coach`)

Read README.md first. This plan connects skating to fitness.

1. Start from the same flow: upload a skating video, pick an age and Beginner/Experienced, measure knee bend, forward lean and stride with browser pose detection (for example MediaPipe Pose).
2. Heart rate: let the user type in Fitbit heart-rate readings for the session (time + beats per minute). Later we may connect the Fitbit directly.
3. Show a simple chart of heart rate over time next to the skating score over time, and point out if form gets sloppy when heart rate goes up. Suggest a rest break when that happens.
4. Dryland mode: upload a video of squats or lunges at home and check them with the same angle method, with kid-friendly tips.

Keep it a single browser page, keep data on the device, and comment the code so kids can follow it. Commit small steps.
